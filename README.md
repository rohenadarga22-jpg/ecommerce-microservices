E-Commerce Microservices

A backend E-Commerce application built using Java 17 and Spring Boot, following a microservices architecture.

Project Status

🚧 Currently under development.

Technology Stack

- Java 17
- Spring Boot 3
- Spring Data JPA
- Hibernate
- MySQL
- REST APIs
- Maven
- Git and GitHub
- Docker (planned)
- AWS integrations (planned)

Planned Microservices

1. Product Service
2. User Service
3. Order Service
4. Inventory Service
5. Payment Service
6. Notification Service
7. API Gateway

Key Learning Objectives

- Build REST APIs using Spring Boot
- Implement CRUD operations
- Integrate MySQL using Spring Data JPA
- Implement exception handling and validation
- Secure APIs using Spring Security and JWT
- Understand microservices communication
- Write unit tests using JUnit and Mockito
- Explore Docker and AWS deployment

Development Approach

The project will be developed incrementally, starting with the Product Service and gradually integrating additional services.
